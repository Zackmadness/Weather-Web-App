# Weather App

A responsive weather application that allows users to search for any location and view current weather conditions along with a 24\-hour forecast. The application uses the Visual Crossing Weather API to fetch real\-time weather data.
Project provided by [Roadmap.sh](https://roadmap.sh/projects/weather-app) 

## Features

- Search weather by city or location
- Display current temperature
- Display wind speed
- Display chance of precipitation
- Display current weather conditions
- View the next 24 hours of forecast data
- Refresh weather information
- Automatically detect and display weather for the user's current location
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6\+)
- Visual Crossing Weather API
- Geolocation API

## Getting Started

### Prerequisites

- A modern web browser
- A Visual Crossing Weather API key

### Installation

1. Clone the repository:

git clone [https://github.com/yourusername/weather\-app.git](https://github.com/yourusername/weather-app.git)

1. Navigate to the project folder:

cd weather\-app

1. Add your API key in script.js:

const API\_KEY = "YOUR\_API\_KEY";

1. Open index.html in your browser.
